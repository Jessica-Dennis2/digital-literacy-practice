5 Tips for Naming Digital Files
5 Consejos para Nombrar Archivos Digitales

FICTIONAL CLASSROOM PRACTICE / PRÁCTICA FICTICIA EN CLASE

  1. Use a clear, descriptive name. / Use un nombre claro y descriptivo.
  2. Include a date when helpful. / Incluya una fecha cuando sea útil.
  3. Avoid names like document1 or scan0001. / Evite nombres como document1 o scan0001.
  4. Keep related files together. / Mantenga juntos los archivos relacionados.
  5. Check the file type before uploading. / Revise el tipo de archivo antes de subirlo.

Example / Ejemplo: Elena_Garcia_Training_Certificate.pdf
