Student Challenge / Reto del Estudiante

  1. Scan your fictional paper document. / Escanee su documento ficticio.
  2. Save it as a PDF. / Guárdelo como PDF.
  3. Rename the file clearly. / Cambie el nombre claramente.
  4. Find the saved file. / Encuentre el archivo guardado.
  5. Use the form above to select it. / Use el formulario para seleccionarlo.
